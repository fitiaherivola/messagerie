🔐 Comment ça marche ?

  • Clé publique : Peut être partagée avec tout le monde. Elle sert à chiffrer les messages destinés à vous.
  • Clé privée : Doit rester secrète. Elle seule permet de déchiffrer les messages chiffrés avec votre clé publique.
  • Algorithme : RSA-2048 avec padding OAEP (SHA-256).
  • Pour les messages longs, utilisez le mode Hybride (RSA + AES) qui évite la limite de taille de RSA.
